The best meal I ever had was instant noodles at 2 a.m. on a rainy night, eaten standing up in the kitchen, and I would trade a five-star dinner for it.

## Run

```sh
node --experimental-strip-types main.ts
```

`main.ts` reads the entry from `entry.txt` and writes it to `output.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`, or `./output` by default). Node standard library only — no network, no wall clock.
